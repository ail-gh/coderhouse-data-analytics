**Proyecto de Análisis de Datos**
Repositorio oficial para el desarrollo del proyecto de análisis de datos orientado al entorno comercial de RetailPro. Este proyecto integra consultas relacionales avanzadas en Microsoft SQL Server y el desarrollo de un tablero interactivo en Power BI para el diagnóstico del negocio. 

*Problema de negocio*
Caída del margen de beneficio global en RetailPro a pesar del incremento constante en el volumen de ventas.

*Herramientas utilizadas*
Base de datos: Microsoft SQL Server
Business Intelligence: Power BI Desktop
Control de versiones: Git y GitHub

*Ejecución de scripts SQL*
Ejecutar los archivos en SQL Server Management Studio (SSMS) en el siguiente orden:
ventas_tech_db.sql: Crea la base de datos, diseña la estructura de tablas e inserta datos.
m4_consultas_negocio.sql: Genera las consultas de negocio y agrupamientos.
m5_consultas_joins.sql: Ejecuta las vistas consolidadas y auditorías con JOINs.
